# 幣圈小百科

給新手的加密貨幣與技術指標中文小百科。一個概念一頁，每頁都用同樣的五個段落說明：一句話定義、原理與計算、怎麼解讀、常見誤區、相關概念。

## 這個專案的重點

網站內容由 AI 依照 [AGENTS.md](AGENTS.md) 的規則產生。規則定義了頁面結構、檔名、分類、寫作風格與新增頁面的流程，所以之後只要一句指令就能新增頁面：

> 請依照 AGENTS.md 新增「MACD」頁面。

## 結構

```
AGENTS.md              專案規則
index.html             首頁
assets/style.css       全站樣式
templates/concept.html 概念頁模板
concepts/              概念頁
```

## 本機預覽

純靜態網站，直接用瀏覽器打開 `index.html` 即可。
